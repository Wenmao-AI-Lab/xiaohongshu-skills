  # 热点分析与爆款挖掘

  ## 技能定位

  **核心价值**：帮助内容创作者快速了解一个话题的热度全貌，发现创作切入角度。

  ## 触发条件

  当用户有以下需求时**必须**使用本技能：

  ### 场景 1：全网热点查询

  - "全网最新的话题有哪些"
  - "最近有什么热点"
  - "现在什么话题最火"
  - "有什么热门话题推荐"
  - "帮我看看全网热搜"

  ### 场景 2：指定话题分析

  - "帮我分析一下 XX 话题的热度"
  - "XX 事件最近有什么爆款内容"
  - "我想了解 XX 话题的关键词"
  - "帮我把 XX 话题的爆款内容挖出来"
  - "XX 话题有什么创作角度"
  - "分析一下 XX 为什么火了"
  - "XX 话题在哪些平台比较火"

  ### 场景 3：选题策划需求

  - "我想做 XX 方向的内容，有什么选题建议"
  - "帮我找一些热门的选题"
  - "最近 XX 领域有什么可以写的"
  - "有什么容易爆的选题推荐"
  - "帮我挖掘一下 XX 的创作角度"

  ### 场景 4：竞品/热点追踪

  - "帮我追踪一下 XX 话题的热度变化"
  - "XX 品牌的营销为什么火了"
  - "分析一下 XX 事件的传播路径"
  - "XX 产品在各个平台的讨论度如何"

  ### 场景 5：内容定位建议

  - "我想做新媒体，选什么方向好"
  - "XX 赛道现在还能做吗"
  - "分析一下 XX 领域的内容机会"
  - "帮我看看 XX 方向还有没有蓝海"

  ## 核心流程

  ```
  输入话题 → 关键词提取 → 多平台搜索 → 数据验证 → 关键词聚合 → 创作角度输出
  ```

  ### Step 1: 关键词提取与扩展

  **输入处理**：

  1. 用户输入话题/事件描述
  2. 提取核心关键词（人名、地名、事件名、产品名等）
  3. 扩展关联关键词：
     - 相关人物/品牌/机构
     - 相关地点/场景
     - 相关话题/标签
     - 相关情绪词/热词

  **输出**：

  ```
  核心关键词：[词1, 词2, 词3]
  关联关键词：[词A, 词B, 词C, ...]
  搜索关键词组合：[组合1, 组合2, 组合3, ...]
  ```
