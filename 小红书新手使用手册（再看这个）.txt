第0章｜先搞懂这个技能包是什么
────────────────────────────────────────────────────

这是一套围绕「小红书运营全流程」组织的 AI 技能包，覆盖 8 大环节：
账号定位与起号 → 选题策划与热点追踪 → 图文内容创作 → 视频内容创作
→ 内容优化与合规审查 → 发布与多平台分发 → 互动与种草转化 → 数据复盘与增长。

共 35 个技能，全部零门槛或低门槛，装好即可用。每个技能是一个「会干活的 AI 助手」，
你用自然语言下指令，它按自己的 SKILL.md 流程帮你产出结果。

┌──────────────────────────────────────────────────┐
│ ⚡ 小白怎么理解「技能」：                                    │
│    你可以把它当成一位随时待命的同事。                             │
│    你说「帮我写篇种草笔记，产品是手工蛋黄酥」，                        │
│    它不会反问一堆问题，而是直接按步骤把成品交给你。                      │
└──────────────────────────────────────────────────┘

第1章｜安装：一次性装好全部技能
────────────────────────────────────────────────────

① 找到本技能包文件夹，每个技能是一个子文件夹（内含 1 个 .zip + 1 份使用说明）。
② 把技能夹整体复制进智能体的 skills 目录（用户级 ~/.workbuddy/skills/ 或项目级 .workbuddy/skills/）。
③ 重启或刷新智能体，在对话里直接 @ 技能名，或用自然语言描述需求即可调用。

┌──────────────────────────────────────────────────┐
│ ⚠️ 安装成功的判断标准：                                    │
│    ① 对话框里 @ 技能名，能自动补全出来                          │
│    ② 说一句需求，它直接给成品，而不是反问你                         │
│    ③ 技能目录下能看到 SKILL.md 这个文件                      │
│    三条都满足 = 装好了。缺哪条，重启一次再看。                       │
└──────────────────────────────────────────────────┘

▌01_账号定位与起号（4 个）

【小红书内容策略规划】
  所属分类：小红书自媒体 · 账号定位与起号
  技能标识：xhs-content-strategy
  依赖门槛：🟢 零门槛 — 无需 API、密钥或付费，安装即用。
  干什么的：把小红书运营拆成「定位 → 选题 → 对标 → 生产 → 发布 → 复盘」六个环节，每个环节都有对应的中文操作手册。不知道下一步干什么的时候，问它就行；也可以直接当一份可执行的运营 SOP 来用。
  怎么用：直接对 AI 说「帮我用 小红书内容策略规划 做 <你的场景>」，或参考使用说明里的触发场景。

【小红书账号定位顾问】
  所属分类：小红书自媒体 · 账号定位与起号
  技能标识：xiaohongshu-account-positioning
  依赖门槛：🟢 零门槛 — 无需 API、密钥或付费，安装即用。
  干什么的：专治"账号做不起来"。它会问清你的身份、资源、目标人群和你能持续输出的东西，再给出人设定位、赛道选择、受众画像和差异化打法。新号和老号都能用。
  怎么用：直接对 AI 说「帮我用 小红书账号定位顾问 做 <你的场景>」，或参考使用说明里的触发场景。

【自媒体赛道定位】
  所属分类：小红书自媒体 · 账号定位与起号
  技能标识：ip-positioning-report
  依赖门槛：🟢 零门槛 — 无需 API、密钥或付费，安装即用。
  干什么的：一份 22 题的自我剖析表，从基础信息、内核价值、人生经历、自媒体认知、行业信息五层往下问。答完自动生成 IP 定位报告：人设名、定位、受众、内容支柱、差异化、变现路径。
  怎么用：直接对 AI 说「帮我用 自媒体赛道定位 做 <你的场景>」，或参考使用说明里的触发场景。

【自媒体起步向导】
  所属分类：小红书自媒体 · 账号定位与起号
  技能标识：start-self-media-cn
  依赖门槛：🟢 零门槛 — 无需 API、密钥或付费，安装即用。
  干什么的：给完全不知道第一步做什么的人。它一次只问一道简单选择题，逐步问清账号定位、目标用户、卖什么、做哪个平台、真人还是 AI、更新频次、预算，最后交付账号方案 + 第一条内容成品 + 7 天打勾计划。
  怎么用：直接对 AI 说「帮我用 自媒体起步向导 做 <你的场景>」，或参考使用说明里的触发场景。

第5章｜新手常见问题 FAQ
────────────────────────────────────────────────────

Q1：技能装了但调不动？
    → 确认 .zip 已解压进 skills 目录、重启智能体，并用 @技能名 或在提示里点名。

Q2：生成内容像 AI 写的？
    → 用「中文去AI味」再过一遍，或创作时多给具体素材（真实经历、真实数据最有效）。

Q3：担心违规限流？
    → 发布前用「笔记违禁词检测」「内容评分修复」「多平台发布审查」三件套体检。

Q4：多平台发同一篇？
    → 用「多平台文章同步发布 / 内容采集排版分发 / 小红书一键发布」按平台微调后分发。

Q5：数据不好怎么改？
    → 用「内容数据诊断器 / 小红书运营副驾」定位问题，回头改选题与封面。

Q6：发布技能点了没反应？
    → 三个排查点：①本机是否装了 Chrome ②是否能打开 9222 端口 ③是否已扫码登录。
      首次使用必须先扫码登录一次，之后才会记住登录状态。

Q7：这些技能花钱吗？
    → 大部分完全免费、本机运行。标 🟡 的技能里，少数需要配置自己的 API Key 或登录平台账号，
      具体在各自的 SKILL.md 里写明了，用之前先看一眼。
