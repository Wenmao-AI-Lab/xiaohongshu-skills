  # 种草炼金术士（zhongcao-alchemist）

  种草炼金术士把「写文案」拆成两个确定性步骤：先拆解卖点，再按平台调性生成多版本，避免空洞套话，并自动去 AI 味让文案像真人随手写。核心价值是「一体化、跨平台、可直接用」，优于单平台模板类工具。

  ## 功能
  1. 卖点拆解：用「卖点提炼四步法」把用户给的产品/服务拆成可写点（人群 / 痛点 / 卖点 / 证据），详见 `references/selling-point-framework.md`
  2. 平台适配：按所选平台调性库（小红书口语种草 / 抖音节奏口播 / 电商转化导向 / 公众号深度 / 朋友圈轻社交）匹配语气与结构，详见 `references/platform-tone-guide.md`
  3. 多版本生成：一次产出 3–5 个版本（种草 / 硬广 / 测评 / 对比 等），直接可用
  4. 合规护航：内置合规红线，规避绝对化用语、虚假/功效宣称，尾部附合规提示
  5. 去 AI 味（串接 humanizer）：生成后默认开启"去 AI 味"润色，让文案像真人随手写，而非机器套模板。详见 `references/humanize-guide.md`

  ## 执行流程
  1. 用户说：给主题/产品 + 目标平台 + （可选）参考卖点
  2. 技能确认：调用 `scripts/build_prompt.py` 前，先复述「平台 + 版本数 + 卖点拆解结果」，请用户确认或补充
  3. 技能执行：运行 `scripts/build_prompt.py`（默认带 `--humanize`）组装结构化提示词（含平台调性 + 卖点拆解 + 多版本指令 + 合规约束 + 去 AI 味指令），再据此生成文案
  4. 技能回复：输出分版本文案，每版本标注适用场景，尾部附合规提示

  ## 去 AI 味（与 humanizer 串接）
  - 触发：默认开启；用户说"不要去味/原样生成"时关闭 `--humanize`
  - 做法：在提示词中注入 humanizer 模式指令（见 `references/humanize-guide.md`），剥促销腔/规则三段/虚浮结论/em dash 滥用/虚词堆叠
  - 平台差异化：小红书/抖音/朋友圈保留适量 emoji 与口语（平台原生调性，不算 AI 痕迹）；电商/公众号用简单陈述句去夸张修饰
  - 实现：`build_prompt.py --humanize` 已内置去味指令块，无需额外调用外部脚本

  ## 用法示例
  - 「帮我写 5 条小红书种草文案，推广一款便携咖啡机，卖点是出差也能喝到现磨」
  - 「给这个护肤精华写电商标题 + 详情页，要 3 个版本」
  - 「生成 3 条抖音口播稿，语气像真实测评博主」
  - 「写文案，原样就行不要去 AI 味」（关闭 --humanize）

  ## 触发词设计
  - 主触发：帮我写[平台]营销文案 / 写[平台]种草文案
  - 覆盖：电商标题、详情页、公众号推文、朋友圈、抖音口播、信息流广告标题/落地页
  - 排除：纯「写文章」「写小说」等非营销目的 → 不触发，交由通用写作技能
  - 冲突：与 humanizer（去 AI 味）不冲突，可串联使用

  ## 异常处理
  - 找不到主题：回复「请告诉我你要推广的产品/服务，以及想发在哪个平台？」
  - 平台不支持：回复支持的平台列表（小红书 / 抖音 / 电商 / 公众号 / 朋友圈），引导用户选择
  - 出错：回复简明错误并给出重试建议

  ## 进度反馈
  - 开始：⏳ 正在拆解卖点并匹配平台调性…
  - 进行：已生成 x/n 个版本…
  - 完成：✅ 已生成 N 个版本，记得看尾部合规提示

  ## 合规红线（生成时必须遵守）
  - 不使用「最/第一/国家级/绝无仅有」等绝对化用语
  - 不编造功效、不夸大效果、不做医疗/保健宣称（除非用户提供合规资质）
  - 不生成虚假用户评价或伪造销量数据
  - 每条输出尾部附一句：「文案需结合真实信息使用，请自行核对合规。」
