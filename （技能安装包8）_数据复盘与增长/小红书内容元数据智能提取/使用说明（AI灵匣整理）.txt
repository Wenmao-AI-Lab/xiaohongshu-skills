  # 小红书内容元数据提取

  ## 概述

  通过内置脚本，从小红书分享链接或发现页链接中提取笔记元数据（标题、描述、类型、时间、作者、互动量、标签、视频流信息等）。

  ## 快速上手

  运行提取器并将 JSON 打印到标准输出：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --pretty
  ```

  将 JSON 写入文件：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --output /tmp/xhs_note.json
  ```

  仅输出扁平化记录：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --flat-only --pretty
  ```

  仅将扁平化记录写入文件：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --flat-only --output /tmp/xhs_flat.json
  ```

  以 JSON 形式输出错误：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --error-json
  ```

  将错误 JSON 写入文件：

  ```bash
  python scripts/xiaohongshu_extract.py "<xhs_url>" --error-json --output /tmp/xhs_error.json
  ```

  ## 工作流程

  1. 用用户提供的链接运行 `scripts/xiaohongshu_extract.py`。
  2. 若脚本找不到 `window.__INITIAL_STATE__`，则请用户提供直接的发现页链接。
  3. 用 JSON 输出汇总笔记元数据，或喂给下游分析。

  ## 输出说明

  脚本返回以下 JSON 对象：

  - `note_id`、`title`、`desc`、`type`、`time`、`ip_location`
  - `user`（昵称、user_id、头像）
  - `interact`（点赞/收藏/评论/分享数，以及归一化的 *_num 值）
  - `tags`
  - `video`（video_id、时长、宽、高、fps、大小、stream_url）
  - `field_mapping`（嵌套字段到扁平字段的映射表）
  - `flat`（含归一化计数与 ISO 时间戳的扁平记录）

  若视频流列表为空，`video` 字段可能为 null 或空。
