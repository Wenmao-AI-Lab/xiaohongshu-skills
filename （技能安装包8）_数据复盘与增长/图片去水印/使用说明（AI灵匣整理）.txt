  # 图片去水印

  按矩形区域擦除图片上的水印、logo、角标、日期戳等叠加内容，用修复算法（inpaint）把擦掉的区域用周围像素重建，尽量看不出痕迹。

  ## 什么时候用它

  - 用户说：去水印、去除水印、消水印、清除图片水印
  - 需要擦掉图片上的 logo、角标、日期戳、平台水印
  - 有一批带水印的图要统一处理

  ## 使用方式

  ### 第 1 步 · 确认水印位置

  先看图片，确认水印所在的矩形区域，记下坐标（左上角为原点）：

  - **像素坐标**：`x,y,w,h`，例如右下角水印 → `--rect 620,860,300,80`
  - **相对坐标**：`0-1` 之间，例如底部整条 → `--rect-pct 0,0.88,1,0.12`

  如果用户说不清位置，可先用 `--rect-pct` 试一版，出图后让用户确认。

  ### 第 2 步 · 执行

  ```bash
  # 装依赖（一次即可）
  pip install opencv-python numpy

  # 单个水印区域
  python scripts/del_watermark.py 原图.jpg 去水印.jpg --rect 100,800,600,120

  # 多个区域（水印 + 角标）
  python scripts/del_watermark.py 原图.jpg 去水印.jpg --rect 620,860,300,80 --rect 20,20,180,60

  # 整目录批量，输出到另一个目录
  python scripts/del_watermark.py ./带水印 ./去水印 --rect 620,860,300,80
  ```

  ### 第 3 步 · 校验与微调

  - 输出后对比原图，看擦除区域有没有残留或明显色块。
  - **有残留** → 把矩形范围放大约 10-20 px 再跑一次。
  - **有明显痕迹** → 提高修复半径：`--radius 9`，或换算法 `--method ns`。
  - 水印特别大或压在复杂纹理上时，如实告知用户：可能需要手工修补，不要承诺"完全无痕"。

  ## 参数说明

  | 参数 | 说明 |
  |------|------|
  | `src` / `dst` | 输入输出路径；都是目录时进入批量模式 |
  | `--rect x,y,w,h` | 像素坐标的水印矩形，可重复使用 |
  | `--rect-pct x,y,w,h` | 相对坐标（0-1）的水印矩形，可重复使用 |
  | `--radius` | 修复半径，默认 5；水印越大调到 7-9 |
  | `--method` | `telea`（默认，适合细窄区域）或 `ns`（适合大面积） |
  | `--suffix` | 批量模式输出文件名后缀 |

  ## 交付物

  去水印后的图片文件、处理前后对照、批量处理命令与参数说明。

  ## 边界

  - 只处理**用户自己有权处理**的素材；不协助去除他人版权水印用于二次发布。
  - 纯色/简单背景效果最好；复杂纹理背景可能有轻微痕迹。
